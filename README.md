# 全球勋奖章图鉴

现有 HTML 与 Android 项目。私有研究版本 v0.029。本次处理本地素材，不新增章种，不改变等级或历史版本身份。

原图、苏联修复参考备份、研究缓存只保留本地。仓库保存运行源码、可移植目录索引和构建规则。HTML ZIP、压缩展示图片及签名 APK 通过既有私有仓库 Releases 提供。

[构建顺序](BUILD.md) · [发布顺序](RELEASE.md)

列表使用≤384像素 WebP，详情使用≤1200像素 WebP。透明图保留所有非零透明度像素并修剪外部画布；纯白矩形边缘只删除完全白色的外围行列。苏联修复图保留原有内容。加3.5%安全边距。不改变铭文、颜色、金属、光照，不推断方向或补画结构。复杂背景和未确认素材继续待核验。

本地根目录 `index.html` 保留原三列表格布局。Release 中 `desktop.html` 为桌面图鉴，`index.html` 为现有手机界面；共用同一目录和展示资源。压缩图不能恢复原始高清图。源码单独检出也不能凭空重建缺失原图；需要原素材时按 BUILD.md 传入外部素材目录。

历史 Git 提交不改写；取消原图当前跟踪不等于删除过去已上传的历史素材。本版不再上传原图库。
